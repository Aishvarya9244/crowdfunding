# CryptoFund

## 🪙 Project Description
CryptoFund is a simple crowdfunding DApp built on the Ethereum blockchain. It allows users to fund a project using ETH, and the project owner can withdraw funds once the target goal is reached.

## 🎯 Project Vision
The vision of CryptoFund is to create a decentralized, transparent, and trustless way to raise funds for creative, social, or tech-based projects without intermediaries.

## ⚙️ Key Features
- **Fund a Project:** Users can contribute ETH to support the project.  
- **Track Total Funds:** Real-time tracking of how much ETH has been raised.  
- **Secure Withdrawals:** Only the project owner can withdraw funds once the goal is met.

## 🚀 Future Scope
- Add multiple projects and funding goals within a single contract.  
- Integrate ERC-20 tokens for funding.  
- Develop a front-end DApp interface with MetaMask support.  
- Implement milestone-based fund releases for better transparency.
